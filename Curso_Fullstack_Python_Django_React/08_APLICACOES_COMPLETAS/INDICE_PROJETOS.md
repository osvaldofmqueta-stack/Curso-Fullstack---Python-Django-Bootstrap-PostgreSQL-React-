# Projetos completos para praticar

Depois de aprenderes o projeto GestorWeb, usa estes percursos para repetir os mesmos conceitos em problemas diferentes.

## Ordem recomendada

### 1. TaskFlow — gestão de tarefas

Pasta: `01_TASKFLOW/`

É o projeto mais simples para praticar:

- CRUD.
- Estados.
- Prioridades.
- Datas.
- Permissões por utilizador.
- Dashboard.

### 2. ContactFlow CRM — clientes e oportunidades

Pasta: `02_CRM_CONTACTOS/`

É o projeto intermédio para praticar:

- Várias relações entre models.
- Contactos e empresas.
- Pipeline de oportunidades.
- Atividades.
- Relatórios comerciais.

### 3. ReservaFácil — agenda e reservas

Pasta: `03_RESERVAS/`

É o projeto mais desafiante para praticar:

- Datas e horários.
- Disponibilidade.
- Conflitos.
- Estados de reserva.
- Regras de negócio.
- Calendário e notificações.

## Método para cada projeto

1. Lê a ilustração antes de começar.
2. Cria o projeto Django vazio.
3. Implementa os models.
4. Cria o Admin.
5. Constrói as páginas com Templates e Bootstrap.
6. Adiciona forms e CRUD.
7. Adiciona login e permissões.
8. Escreve testes.
9. Cria API.
10. Se fizer sentido, cria frontend React.
11. Adiciona relatórios.
12. Documenta e publica.

Não copies o código do projeto anterior sem perceber. Reutiliza a estrutura, mas escreve os nomes, regras e decisões do novo domínio.
