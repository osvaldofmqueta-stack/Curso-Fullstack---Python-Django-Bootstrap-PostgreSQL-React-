# Projetos zipados por aula

Cada aula tem um ZIP com `STARTER/`, `EXPECTED/`, `ESTADO_ESPERADO.md`, `CHECKLIST.md` e um exemplo de estrutura/código.

## Regra de uso

1. Extrai o ZIP da aula atual.
2. Trabalha primeiro a partir de STARTER.
3. Usa EXPECTED apenas para comparar depois.
4. Nunca copies a solução antes de tentares.
5. Guarda o teu resultado real fora do ZIP de referência.
